# FlowMind AI - Video Walkthrough Guide

## Setup Video Script (3 minutes)

### Scene 1: Introduction (0:00 - 0:30)
- Show the GitHub repository
- Explain: "FlowMind AI is a RAG-powered document Q&A dashboard"
- Mention: React 19, TypeScript, Vite, Tailwind CSS 4, Framer Motion

### Scene 2: Installation (0:30 - 1:00)
- Open terminal in project folder
- Run: `cd frontend && npm install --legacy-peer-deps`
- Run: `npm run dev`
- Show browser opening to http://localhost:5173

### Scene 3: Dashboard Tour (1:00 - 2:00)
- **Home page**: Show stats cards, query volume chart, recent activity
- **Documents page**: Show 3 indexed PDFs, upload zone, document cards
- **Conversations page**: Show filters, conversation cards with confidence
- **Analytics page**: Show 4 charts (area, bar, pie, line), top questions table
- **Playground page**: Type a question, show AI response, tech details panel
- **Costs page**: Show $0.00 costs, free tier usage, optimization tips
- **Notifications page**: Show notification categories, filter tabs

### Scene 4: Theme & Settings (2:00 - 2:30)
- Toggle dark mode
- Show theme customizer
- Show settings page

### Scene 5: Wrap-up (2:30 - 3:00)
- Show production build: `npm run build`
- Mention deployment to Vercel/Netlify
- Call to action: star the repo, share feedback

## Key Talking Points

- **Demo Mode**: Works 100% standalone — no backend needed
- **Glassmorphism UI**: Modern glass-effect design with backdrop blur
- **Framer Motion**: Smooth page transitions and micro-animations
- **Recharts**: 5 different chart types across Analytics and Costs
- **TypeScript**: Fully typed with strict mode
- **Component Library**: 25+ reusable UI components
